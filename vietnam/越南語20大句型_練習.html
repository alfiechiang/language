越南語 20 大句型

每個句型 3 個例句，點擊例句聽發音。灰色小字是逐字對照，方便看出語序。發音以北部（河內）腔為準。

→ 進階句型 21–30

1

是～（判斷句）

A + là + B

là 相當於「是」，只用在名詞前面。形容詞前面不加 là（見句型 3）。

▶Tôi là người Đài Loan.我是台灣人。我 / 是 / 人 / 台灣▶Đây là bạn tôi.這是我朋友。這 / 是 / 朋友 / 我▶Anh ấy là bác sĩ.他是醫生。他 / 是 / 醫生
2

不是～

A + không phải là + B

否定 là 句要用 không phải (là)，不能只說 không là。

▶Tôi không phải là sinh viên.我不是學生。我 / 不是 / 學生▶Đây không phải là xe của tôi.這不是我的車。這 / 不是 / 車 / 的 / 我▶Cô ấy không phải là người Việt.她不是越南人。她 / 不是 / 人 / 越南
3

形容詞句：很～／太～了

S + rất + Adj　／　S + Adj + lắm / quá

形容詞直接當謂語。rất 放前面；lắm、quá 放後面，quá 帶有驚嘆語氣「太…了」。

▶Phở này rất ngon.這碗河粉很好吃。河粉 / 這 / 很 / 好吃▶Hôm nay trời nóng quá!今天天氣好熱啊！今天 / 天 / 熱 / 太▶Cô ấy đẹp lắm.她很漂亮。她 / 漂亮 / 很
4

動詞句與否定

S + (không) + V + O

語序和中文一樣是「主詞＋動詞＋受詞」。否定在動詞前加 không。

▶Tôi ăn cơm.我吃飯。我 / 吃 / 飯▶Tôi không uống cà phê.我不喝咖啡。我 / 不 / 喝 / 咖啡▶Chị ấy không biết tiếng Anh.她不會英文。她 / 不 / 會 / 英文
5

是非問句：～嗎？

S + có + V/Adj + không?

最常用的問句。回答「是／有」說 Có，「不」說 Không。

▶Anh có khỏe không?你好嗎？你 / 有 / 健康 / 不▶Em có thích ăn phở không?你喜歡吃河粉嗎？你 / 有 / 喜歡 / 吃 / 河粉 / 不▶Cái này có đắt không?這個貴嗎？這個 / 有 / 貴 / 不
6

疑問詞：什麼、誰、哪裡

… gì? ／ … ai? ／ … ở đâu?

疑問詞放在原本答案的位置，不用移到句首，和中文一樣。

▶Bạn tên là gì?你叫什麼名字？你 / 名字 / 是 / 什麼▶Anh ấy là ai?他是誰？他 / 是 / 誰▶Nhà vệ sinh ở đâu?廁所在哪裡？廁所 / 在 / 哪裡
7

多少、幾：bao nhiêu／mấy

bao nhiêu + N ／ mấy + N

bao nhiêu 問較大或不確定的數量；mấy 問小數目（約十以內），也用在問時間。

▶Cái này bao nhiêu tiền?這個多少錢？這個 / 多少 / 錢▶Bạn bao nhiêu tuổi?你幾歲？你 / 多少 / 歲▶Bây giờ là mấy giờ?現在幾點？現在 / 是 / 幾 / 點
8

時態：đã／đang／sẽ

S + đã / đang / sẽ + V

越南語動詞不變化，用時間詞表示：đã 已經（過去）、đang 正在、sẽ 將會。有時間詞時常可省略。

▶Tôi đã ăn rồi.我已經吃了。我 / 已經 / 吃 / 了▶Tôi đang học tiếng Việt.我正在學越南語。我 / 正在 / 學 / 越南語▶Ngày mai tôi sẽ đi Hà Nội.明天我會去河內。明天 / 我 / 將 / 去 / 河內
9

～了沒？：chưa／rồi

S + (đã) + V + chưa?　→ Rồi / Chưa

問「…了沒」。回答「已經…了」說 Rồi，「還沒」說 Chưa。加 bao giờ 就是問經驗「曾經…過嗎」。

▶Bạn ăn cơm chưa?你吃飯了沒？你 / 吃 / 飯 / 沒▶Chưa, tôi chưa ăn.還沒，我還沒吃。還沒 / 我 / 還沒 / 吃▶Bạn đã đến Việt Nam bao giờ chưa?你去過越南嗎？你 / 已 / 到 / 越南 / 何時 / 沒
10

想要～：muốn

S + muốn + V / N

muốn 後面接動詞或名詞都可以。

▶Tôi muốn uống nước.我想喝水。我 / 想 / 喝 / 水▶Tôi muốn đi Đà Nẵng.我想去峴港。我 / 想 / 去 / 峴港▶Bạn muốn ăn gì?你想吃什麼？你 / 想 / 吃 / 什麼
11

可以、會：có thể／được

S + có thể + V　／　S + V + được

có thể 放動詞前；được 放動詞（或受詞）後，表示「能、會、可以」。不 được 表示「不准」。

▶Tôi có thể ngồi đây không?我可以坐這裡嗎？我 / 可以 / 坐 / 這裡 / 不▶Anh nói được tiếng Việt không?你會說越南語嗎？你 / 說 / 能 / 越南語 / 不▶Ở đây không được hút thuốc.這裡不准抽菸。在 / 這裡 / 不 / 准 / 抽菸
12

給我～、讓我～：cho tôi

Cho tôi + N　／　Cho tôi + V

點餐、買東西最實用。cho 是「給、讓」。句尾加 nhé 或 ạ 會更客氣。

▶Cho tôi một ly cà phê sữa đá.給我一杯冰牛奶咖啡。給 / 我 / 一 / 杯 / 咖啡 / 奶 / 冰▶Cho tôi xem thực đơn.讓我看一下菜單。讓 / 我 / 看 / 菜單▶Cho tôi tính tiền.我要結帳。讓 / 我 / 算 / 錢
13

請～、不要～：hãy／đừng／xin mời

Hãy + V　／　Đừng + V　／　Xin mời + V

hãy 勸人去做；đừng 叫人不要做；xin mời 是禮貌的「請」。

▶Hãy nói chậm một chút.請說慢一點。請 / 說 / 慢 / 一點▶Đừng lo.別擔心。別 / 擔心▶Xin mời vào.請進。請 / 進
14

有～、在～：có／ở

(Ở + 地點) + có + N　／　S + ở + 地點

có 表示「有」；ở 表示「在、住在」。

▶Ở đây có wifi không?這裡有 wifi 嗎？在 / 這裡 / 有 / wifi / 不▶Tôi có hai anh trai.我有兩個哥哥。我 / 有 / 兩 / 哥哥▶Tôi ở Đài Bắc.我住在台北。我 / 在 / 台北
15

需要、必須：cần／phải

S + cần + V/N　／　S + phải + V

cần 是「需要」；phải 是「必須、得」。không cần 表示「不用」。

▶Tôi cần đi bệnh viện.我需要去醫院。我 / 需要 / 去 / 醫院▶Hôm nay tôi phải đi làm.今天我得去上班。今天 / 我 / 必須 / 去 / 工作▶Bạn không cần trả tiền.你不用付錢。你 / 不 / 需要 / 付 / 錢
16

比較：hơn／nhất／bằng

A + Adj + hơn + B　／　Adj + nhất　／　A + Adj + bằng + B

形容詞在前，比較詞在後：hơn 比較、nhất 最、bằng 一樣。

▶Hà Nội lạnh hơn Sài Gòn.河內比西貢冷。河內 / 冷 / 比 / 西貢▶Cái này rẻ nhất.這個最便宜。這個 / 便宜 / 最▶Tôi cao bằng anh ấy.我跟他一樣高。我 / 高 / 等於 / 他
17

因為…所以…：vì…nên…

Vì + 原因 + nên + 結果　／　Tại sao…? → Vì…

tại sao 問「為什麼」，用 vì 回答。

▶Vì trời mưa nên tôi ở nhà.因為下雨，所以我待在家。因為 / 天 / 雨 / 所以 / 我 / 在 / 家▶Tại sao bạn học tiếng Việt?你為什麼學越南語？為什麼 / 你 / 學 / 越南語▶Vì tôi thích Việt Nam.因為我喜歡越南。因為 / 我 / 喜歡 / 越南
18

如果…就…：nếu…thì…

Nếu + 條件 + thì + 結果

thì 相當於「就」，口語中可以省略。

▶Nếu rảnh thì đi cà phê với tôi nhé.如果有空，就跟我去喝咖啡吧。如果 / 有空 / 就 / 去 / 咖啡 / 和 / 我 / 吧▶Nếu đắt quá thì tôi không mua.如果太貴，我就不買。如果 / 貴 / 太 / 就 / 我 / 不 / 買▶Nếu cần gì thì gọi cho tôi.如果需要什麼，就打給我。如果 / 需要 / 什麼 / 就 / 打 / 給 / 我
19

雖然…但是…：tuy／mặc dù…nhưng…

Tuy / Mặc dù + A + nhưng + B

nhưng 是「但是」，也可以單獨使用。vẫn 是「仍然」，常常和這個句型一起出現。

▶Tuy đắt nhưng rất ngon.雖然貴，但是很好吃。雖然 / 貴 / 但是 / 很 / 好吃▶Tôi muốn đi nhưng tôi bận.我想去，但是我很忙。我 / 想 / 去 / 但是 / 我 / 忙▶Mặc dù mệt nhưng tôi vẫn đi làm.雖然累，我還是去上班。雖然 / 累 / 但是 / 我 / 仍然 / 去 / 工作
20

被～：bị／được

S + bị + V（不好的事）　／　S + được + V（好的事）

bị 用在倒楣、受害的事，例如生病、丟東西；được 用在好事，例如被稱讚、得到。

▶Tôi bị cảm.我感冒了。我 / 被 / 感冒▶Tôi bị mất ví.我的錢包不見了。我 / 被 / 丟 / 錢包▶Cô ấy được khen.她被稱讚了。她 / 得 / 稱讚
