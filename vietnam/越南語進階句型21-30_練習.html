21

量詞：cái／con／chiếc／quyển

數字 + 量詞 + 名詞 (+ này / đó)

名詞前面常常要加量詞，跟中文的「件、隻、本」一樣。cái 用於一般物品；con 用於動物；chiếc 用於交通工具；quyển（南部說 cuốn）用於書。「這本書」是 quyển sách này，này 放在最後。

▶Tôi muốn mua hai cái áo.我想買兩件衣服。我 / 想 / 買 / 兩 / 件 / 衣服▶Nhà tôi có một con mèo.我家有一隻貓。家 / 我 / 有 / 一 / 隻 / 貓▶Quyển sách này bao nhiêu tiền?這本書多少錢？本 / 書 / 這 / 多少 / 錢
22

時間子句：khi／trước khi／sau khi

Khi / Lúc + 子句, …　／　trước khi / sau khi + V

khi、lúc 是「…的時候」；trước khi 是「…之前」；sau khi 是「…之後」。

▶Khi tôi đến, anh ấy đã đi rồi.我到的時候，他已經走了。時候 / 我 / 到 / 他 / 已 / 走 / 了▶Rửa tay trước khi ăn.吃飯前要洗手。洗 / 手 / 之前 / 吃▶Sau khi tan làm, tôi đi tập thể dục.下班後我去運動。之後 / 下班 / 我 / 去 / 運動
23

剛剛、快要：vừa／mới／sắp

S + vừa / mới / vừa mới + V　／　S + sắp + V (+ rồi)

vừa、mới、vừa mới 都是「剛剛」；sắp 是「快要」，句尾常加 rồi。

▶Tôi vừa mới ăn xong.我剛吃完。我 / 剛剛 / 吃 / 完▶Anh ấy mới đến Việt Nam.他剛來越南。他 / 剛 / 到 / 越南▶Xe buýt sắp đến rồi.公車快到了。公車 / 快要 / 到 / 了
24

經驗：曾經～過、從沒～過

S + đã từng + V　／　S + chưa bao giờ + V

đã từng 是「曾經…過」；chưa bao giờ 是「從來沒…過」。問別人的經驗時用 đã từng … chưa?

▶Tôi đã từng ăn bún chả.我吃過烤肉米線。我 / 曾經 / 吃 / 烤肉米線▶Tôi chưa bao giờ đi Huế.我從來沒去過順化。我 / 從未 / 去 / 順化▶Bạn đã từng đến Hội An chưa?你去過會安嗎？你 / 曾經 / 到 / 會安 / 沒
25

也、都：cũng／đều

S + cũng + V　／　S（複數）+ đều + V　／　疑問詞 + cũng + …

cũng 是「也」；đều 是「都」，主詞要是兩個以上。疑問詞後面加 cũng，意思就是「每個都…」，例如 món nào cũng 是「哪道菜都…」。

▶Tôi cũng thích phở.我也喜歡河粉。我 / 也 / 喜歡 / 河粉▶Chúng tôi đều là người Đài Loan.我們都是台灣人。我們 / 都 / 是 / 人 / 台灣▶Món nào cũng ngon.每道菜都好吃。道菜 / 哪 / 也 / 好吃
26

還是、或者：hay／hoặc

A + hay + B?　／　A + hoặc + B

問句用 hay，意思是「還是」；陳述句用 hoặc，意思是「或者」。口語裡陳述句也常說 hay。

▶Anh uống trà hay cà phê?你喝茶還是咖啡？你 / 喝 / 茶 / 還是 / 咖啡▶Đi bộ hay đi xe máy?走路還是騎機車？走路 / 還是 / 騎 / 機車▶Thứ bảy hoặc chủ nhật đều được.星期六或星期天都可以。星期六 / 或者 / 星期天 / 都 / 可以
27

完、光：xong／hết

V + xong (rồi)　／　hết + N (rồi)

xong 是「做完」；hết 是「用完、沒了、賣完」。這兩個字後面常加 rồi。

▶Tôi làm xong rồi.我做完了。我 / 做 / 完 / 了▶Hết tiền rồi.錢用光了。光 / 錢 / 了▶Bánh mì hết rồi.麵包賣完了。麵包 / 完 / 了
28

越…越…：càng…càng…

càng + A + càng + B　／　càng ngày càng + Adj

càng ngày càng 是固定說法，意思是「越來越…」。

▶Càng học càng thích.越學越喜歡。越 / 學 / 越 / 喜歡▶Càng nhanh càng tốt.越快越好。越 / 快 / 越 / 好▶Trời càng ngày càng lạnh.天氣越來越冷。天 / 越 / 日 / 越 / 冷
29

一邊…一邊…、又…又…：vừa…vừa…

S + vừa + V1 + vừa + V2　／　vừa + Adj1 + vừa + Adj2

接兩個動詞是「一邊…一邊…」；接兩個形容詞是「又…又…」。

▶Anh ấy vừa ăn vừa xem tivi.他一邊吃飯一邊看電視。他 / 一邊 / 吃 / 一邊 / 看 / 電視▶Cô ấy vừa đi vừa hát.她邊走邊唱。她 / 邊 / 走 / 邊 / 唱▶Quán này vừa rẻ vừa ngon.這家店又便宜又好吃。店 / 這 / 又 / 便宜 / 又 / 好吃
30

修飾名詞：của／mà

N + của + 人　／　N + (mà) + 子句

和中文的順序相反：名詞放前面，修飾語放後面。của 表示「…的」（所屬）；mà 用來帶出一個子句，口語裡常常省略。

▶Đây là xe của anh tôi.這是我哥哥的車。這 / 是 / 車 / 的 / 哥哥 / 我▶Cái áo mà tôi mua hôm qua rất đẹp.我昨天買的那件衣服很漂亮。件 / 衣服 / (mà) / 我 / 買 / 昨天 / 很 / 漂亮▶Người mà bạn gặp hôm qua là ai?你昨天見的那個人是誰？人 / (mà) / 你 / 見 / 昨天 / 是 / 誰
